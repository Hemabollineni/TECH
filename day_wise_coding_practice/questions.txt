##Q6. Pytest – Testing 
File: d6_pytest.py

Given: Write a function called calculate() that accepts two numbers and an operation.
def calculate(a, b, operation):
    if operation == "add":
        return a + b
    elif operation == "subtract":
        return a - b
    elif operation == "multiply":
        return a * b
    elif operation == "divide":
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    else:
        raise ValueError("Invalid operation")


Your tasks:
1. Write test_add() to verify calculate(10, 20, "add") returns 30.
2. Write test_subtract() to verify calculate(30, 10, "subtract") returns 20.
3. Write test_multiply() to verify calculate(5, 4, "multiply") returns 20.
4. Write test_divide() to verify calculate(20, 5, "divide") returns 4.
5. Write test_divide_by_zero() to verify that dividing by zero raises ValueError.
6. Write test_invalid_operation() to verify that an unsupported operation raises ValueError.
Rules:
- Use Pytest's assert statements.
- Use pytest.raises() for error testing.
- Write all code in d6_pytest.py.
- Don't just test the function manually; run it using Pytest.
Expected result: Six test cases should pass
